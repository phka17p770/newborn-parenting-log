# 吃促排卵药后大约多久排卵，促排卵药片什么时候吃

> 更新时间：2026-09-11 (UTC+8)

怀孕生子是女性的人生大事之一。但有些女性因为种种原因，导致排卵异常，降低了怀孕的几率或患上不孕症。对于有排卵障碍的女性朋友，医生一般会建议服用促排卵药，以促进排卵，从而顺利怀孕，那么你知道吃促排卵药后大约多久排卵吗？下面就跟着小编一起来看看问题的答案吧。
吃促排卵药后大约多久排卵
　　 一般而言，吃了排卵药，具体的排卵时间，因为每个女性身体的差异，且体制的不同，也出现一定的差异。并不是说百分百，吃了排卵药之后多久就能够排卵，实现受精以及怀孕的目的，需要根据具体情况进行具体的分析，一般在月经周期第10天开始每2天做一次B超监测，观察卵泡直径的变化，排卵后卵泡消失，连续监测可见在排卵前卵泡不断长大，当发现卵泡直径达18毫米时，则可以准备同房或者取卵做试管婴儿，当最大的卵泡消失时，提示发生排卵。

　　也有不少的女性，在结婚之后多年不孕，把其他引起不怀孕的相关疾病治愈之后，在医生的指导下不用促排卵的药物进行怀孕。但是促排卵的药物有一定的副作用，他会使得您体中的优质卵子一同排出，让您出现多胞胎，虽然给你带来惊喜，但也无疑给你造成了一定的风险以及负担。
促排卵药片什么时候吃
　　 促排卵药目前最常用的就是克罗米芬、来曲唑，还有一些乳腺疾病，可以用他莫昔芬这类的促排卵药。通常在病人来月经的第2-5天开始吃，剂量会根据病人卵巢上卵泡数目及血清激素水平，由医生去具体界定。

　　常规剂量是5天，如果需要还可以延长2-3天，吃排卵药的时候还需要去监测卵泡的发育情况，需要通过超声波连续监测，看卵泡是否长起来，同时还需要查看体内雌激素水平是否升高，也就是根据卵泡的大小及卵泡反应出的雌激素水平，去了解卵泡是否发育、成熟，如果成熟后，就有机会怀孕。建议在月经第5日开始每天给予50-100mg的氯米芬，连续使用5天。治疗剂量的选择要根据患者的体重或者基础代谢率，女性的年龄，以及不孕的原因。并且根据抽血查的孕酮以及做的卵泡监测B超来调整用药。因为使用促排卵药物可能会导致黄体功能不足，卵子质量欠佳，所以一定要结合卵泡监测B超和孕酮监测
