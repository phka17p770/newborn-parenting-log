# 母猪厌食别小看，严重时可致不孕，解决措辞看这里！

> 更新时间：2026-09-15 (UTC+8)

母猪厌食、不爱吃食这种现象，一直是我们很多养殖户都比较头疼的问题。随着养猪业集约化、规模化进程的加快，猪场母猪的“亚健康”状态越来越普遍，抵抗力低让母猪在产仔前后最容易出现状况。母猪厌食更加显著，严重时可致不孕等，那该怎么解决呢？下面小助手带大家一起来了解下。

　　母猪产前、产后不食是实际生产中非常常见的一种现象，但养猪人要注意区分是病理性还是正常生理现象。母猪生产前后一两天出现食欲不振乃至厌食属于正常现象。据了解，母猪生产前后所受应激较大，不食现象是妊娠母猪机体的一种自我调节方式。但如果超过一两天，症状仍未有缓和则需要重视，检测是否是疾病等因素导致，而后及时采取相应措施。

　　母猪不食症状轻则导致母猪消瘦、胎儿初生重下降，更为直接的表现是造成泌乳机能下降。仔猪吃不到奶水会导致腹泻，抵抗力减弱，生长缓慢甚至变成僵猪或发生衰竭死亡；最严重程度的是母猪因顽固性不食而消瘦，出现断奶后乏情，或虽能发情配种，却下一胎产子数低，或久配不孕。

一、母猪不食原因

1、发热性疾病。

母猪在出现身体发热、体温超过正常数值的时候，就会出现厌食、不爱吃食的情况。但是导致母猪发热的原因有非常多，细菌类和病毒类的疾病都有，我们要搞清楚这里面存在的原因，使用对症的药物来治疗。

2、饲料发霉变质。

我们给母猪喂的饲料，如果里面有霉菌毒素，那么就会导致饲料的味道发生一些细微的变化，由于猪的嗅觉和味觉都比较灵敏，我们在喂了这种饲料以后，就会导致母猪出现厌食、不爱吃食这种现象。

3、消化道疾病。

一些母猪的厌食症、不爱吃食，可能是由于消化道疾病造成的。母猪比较常见的消化道疾病有胃溃疡和胃肠炎等，这些疾病都会影响到母猪的食欲。

4. 温度过高。

有时候我们圈舍里面温度过高的时候，就会影响到母猪的食欲，使母猪出现厌食的现象。其实不光是母猪，各个阶段的猪，都会因为圈舍温度高而出现厌食、不爱吃食的问题。

二、解决措施

　　1、当母猪食欲不振时，可先对其进行简单的检查判断。一般来说母猪出现较为明显的厌食情况时，首先观察母猪精神状态，出现精神沉郁、反应迟钝要注意；再检查排便情况，是否存在便秘、排“算盘珠”样粪便的情况；最后再看体温情况，耳尖发凉、体温异常要及时采取措施。

　　2、针对母猪细菌感染产生炎症发烧导致母猪不食的情况，一般的感冒发烧，可以用柴胡加阿莫西林或者青霉素肌注，退烧消炎就可以了。而对于产后子宫炎、乳房炎等炎症引起的发烧，选择输液效果较好。第一瓶用鱼腥草、青霉素加生理盐水，第二瓶用葡萄糖加维生素C，最后用两瓶100ml的甲硝唑。一般产后输液一次就可以了，但如果第二天还是发烧的话就用氨基比林加阿莫西林再肌注。如此退烧后母猪食欲就会恢复。还可以在饲料中添加速壮丁来保护及修复母猪受损肠道粘膜，促进消化，快速恢复母猪食欲，同时还能预防母猪子宫炎、乳房炎、缺乳症等问题，缩短产程，平时也可以预防使用。

　　3、另一方面就是加强饲养管理。吴旭东表示，根据情况在配种一个月后给予母猪适量运动，同时注意加强母猪营养，可以添加益生菌或者补充饲喂青绿饲料。另外，由于肝脏是最大的解毒器官，又是脂肪、蛋白质、糖代谢的重要场所，肝功能受损对母猪影响很大。所以我们一定要用解百毒，来保护母猪肝肾健康，中止炎症反应，解毒排毒，缩短病程，快速恢复食欲。如果是霉菌毒素引起的，可以在饲料中拌入霉特净、战霉等脱霉剂，孕畜可用，快速抑制杀灭霉菌的生长，防脱治三效合一，而且好用不贵。

4、生产中还有体温低于正常的母猪不食现象，这是因为应激导致能量不足。可以肌注樟脑磺酸钠提高体温；若是母猪在妊娠期，还需要肌注黄体酮以安胎。我们也可在饲料中加入三元VC、蓝钻多维、金芪维等，补充多种维生素电解质和营养物质，保障母猪营养充足，同时提高母猪免疫抗应激。
