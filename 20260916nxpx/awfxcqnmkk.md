# 8年病痛，1次解决| 看机器人如何解决输尿管狭窄难题

> 更新时间：2026-09-16 (UTC+8)

无论是儿童还是成年人

输尿管狭窄引发的肾积水等问题

都曾是临床治疗中的 “老大难”。

然而

在厦门大学附属第一医院泌尿外科

一场场关乎“生命通道”重建的精细手术

正悄然改变患者的命运。

从因延误治疗而痛苦不堪的五岁孩童，到饱受八年病痛折磨的成年患者，达芬奇机器人手术系统的出现，为尿路疾病患者带来了从“反复修补”到“一次根治”的新希望，也标志着泌尿外科手术已迈入精准医疗新时代。

**病例一**

**八年折磨，终迎转机**

小芳（化名）在过去八年里，右侧腰部酸痛反复发作，经历多次手术仍无法根治输尿管狭窄问题，从输尿管狭窄到继发结石，从肾盂积水到反复扩张……

传统手术方式如同为年久失修的隧道临时加固，始终未能实现根本性重建。

而今，一场革命性的手术——机器人辅助舌黏膜补片输尿管成形术，为她带来了终结困扰的希望。

** 巧取“材”**

**移花接木，舌黏膜成理想补片**

手术关键一步在于获取理想的“修补材料”。

泌尿外科联合耳鼻喉科苏若为主任医师团队，从小芳舌下精准获取长约5cm的黏膜组织。

该黏膜血管丰富、生物相容性极佳，是修复输尿管狭窄的绝佳材料，且取材处一周后可自行愈合。

术前CTU提示输尿管上段长段狭窄

术中取下的舌粘膜组织

**精缝合**

**毫米间的艺术**

接下来是最考验技术的环节：找到狭窄段，切开狭窄段，舌粘膜缝合修补。

主刀医生陈跃东主任医师术中采用可视化技术精准判断狭窄段输尿管，纵向切开狭窄段输尿管，操控机械臂，用比头发丝更细的可吸收缝合线，将这片柔软的舌黏膜像“打补丁”一样，精准地缝合到被切开并修剪成形的狭窄输尿管上。

机器人的机械臂拥有超越人手的稳定性和灵活性，能在深部腔道内、毫米级组织上的精准缝合，确保吻合口严密无渗漏，同时保证血液供应，让这片“移植过来的新管道”能够顺利存活。

**破困局**

**从“反复修”到“一次成”**

“对于患者这样经历过多次手术的复杂输尿管狭窄，局部组织疤痕严重，单纯扩张极易再次狭窄。”主刀医生陈跃东主任解释道，“机器人舌黏膜修复术的优势在于，它不再依赖于原本已经瘢痕化的输尿管，而是用健康的自体组织，为患者‘再造’了一段宽敞、有弹性的新通道，从而实现了从‘临时疏通’到‘根本性重建’的跨越。”

**病例二**

**5岁娃腹痛不止 竞是输尿管狭窄**

小欣妈妈回忆，早在产检时就发现胎儿右肾积水，但因缺乏专业认知，孩子出生后未进一步检查。

直到5个月前，小欣频繁腹痛、恶心呕吐，疼到大汗淋漓，家长才慌了神，带他就诊。

检查结果揪心：

MRU 显示右侧肾盂肾盏扩张、积液，右侧输尿管起始段疑狭窄；肾动态显像 + 肾小球滤过率检查，也发现左肾排泄延缓、右肾排泄受阻，右侧肾脏功能降低。

最终诊断为：“右侧肾盂输尿管连接处狭窄（合并右肾积水）。” 

小欣术前磁共振提示右侧肾盂输尿管连接处狭窄

若采用传统开放手术，需在腹部切开较长切口，对孩子创伤大、恢复慢。

陈跃东主任团队决定采用达芬奇机器人腹腔镜技术，实施微创肾盂成形术。

术中仅在腹部做数个微小切口，利用机械臂灵活、视野清晰的优势，精准分离并切除狭窄段输尿管。术后小欣恢复顺利，目前已康复出院。

**机器人精准手术，成功率超90%**

达芬奇机器人手术系统作为目前“世界上最先进的微创机器人手术系统”之一，拥有超高清三维视野便于解剖结构识别，大大减少误伤操作。其微创、机械臂精细灵活、操作精准稳定的特点，对于泌尿外科而言，特别是上尿路重建手术，这些优势尤为关键。

达芬奇辅助下输尿管狭窄修复成功率可至90%以上，尤其对处理长度大于3cm、多次手术失败的“疑难杂症”优势突出。

截至目前，厦大附一泌尿外科已完成40余例达芬奇机器人辅助上尿路重建手术，涵盖多种复杂情况： “输尿管狭窄多次手术失败后的修复”、“长段、多段输尿管狭窄”“先天性输尿管狭窄梗阻、低龄患儿重建”以及需要“自体组织移植重建”的疑难病例。

**特色体系：个体化手术，精准功能重建**

在达芬奇机器人平台赋能下，厦门大学附属第一医院泌尿外科已构建起一整套成熟、多元的上尿路重建技术体系，可根据患者狭窄部位、长度、病因及自身组织条件，量身定制最优术式：

**多种术式**

**机器人辅助舌黏膜补片输尿管成形术：**适用于长段输尿管狭窄且自身组织无法直接吻合的复杂情况。

**机器人辅助腹腔镜肾盂成形术：**解除UPJO导致肾积水的“金标准”疗法。

**机器人辅助输尿管端端吻合术/膀胱肌瓣输尿管成形术：**适用于中下段输尿管局限性狭窄或损伤。

从经典肾盂成形到组织替代，从局部修补到全段重建，厦大附一泌尿外科凭借达芬奇机器人这一“超级工具”与深厚临床经验，建立起上尿路重建完整技术解决方案，致力于为每一位患者守住肾功能的生命通道。
